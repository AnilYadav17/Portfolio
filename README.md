## ✨ Features & Highlights

- **Sleek Frosted Glassmorphism**: Frosted navigation bar (`backdrop-filter: blur(18px)`), glassmorphic code terminal, and interactive project cards with ambient glow lighting.
- **Modern Typography**: High-contrast, clean visual hierarchy powered by Google Fonts (**Manrope** for body/headings and **DM Mono** for code, tags, and timestamps).
- **Responsive Bootstrap 5 Grid**: Fully fluid and adaptive across mobile, tablet, and desktop screens with zero layout shifts.
- **Interactive Python Terminal**: Code editor component simulating real-time Python scripting with syntax highlighting and a blinking cursor.
- **Direct GitHub Repository Links**: Each project card features a direct `GitHub ↗` link button and real repository metrics (⭐ stars and 🍴 forks).
- **Lightweight & High Performance**: Clean, beginner-friendly code with zero heavy JavaScript frameworks. Fast page loads directly from CDNs.
